One sentence, 204 characters, that would convince a friend who has never coded to
let an AI agent build their first app idea on
[make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

The program (`main.ts`) writes that sentence to `/output/entry.txt` — UTF-8,
no trailing newline. That sentence is the whole entry: no code, no explanation.

Entry for the [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3)
competition on make.fun.
